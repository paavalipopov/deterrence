# Deterrence vocabulary

| Term | Meaning |
| --- | --- |
| Deterrence | The mod name and total value subtracted from threat wealth. |
| Remains | Maintained bodies and kept prisoner organs, plus individual body fading tails. |
| Reputation | One shared fading balance of one-time acts. |
| Hazards | The combined total of separately growing/fading environmental types. |
| Gain | Value added by one qualifying act. |
| Fade | The gradual loss of a balance. |
| Game threat wealth | Game wealth input used for threats, after Misc adjustments; buildings count at half value. |
| Adjusted threat wealth | max(0, Game threat wealth - Deterrence) x biome factor. |

Biome factor is an immediate formula factor. The surface multiplier adjusts its Game threat wealth input under Misc. Neither creates another meter. Settings use these same terms. Antiwealth remains only in compatibility identifiers and historical documents.
