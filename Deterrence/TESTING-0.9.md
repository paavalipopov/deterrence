# Deterrence 0.9.0 in-game checks

| Check | Expected result |
| --- | --- |
| Toggle deterrence, biome, and island on Formula | The large formula shows the active terms. Biome and qualifying-island lines share a plot. |
| Set the island tile limit and multiplier | An enclosed landmass within the limit qualifies. The default tile limit is 10. |
| Check an island with another settlement | Require sole settlement leaves factor 1. Clearing the check allows the configured factor when the island meets the tile limit. |
| Open Deterrence from World’s right | The compact shield opens the meters and history. Formula Options still offers Open meters. |
| Change growth and fade controls | The plot remains visible and responds as you edit the controls. |
| Save and reload a named preset | Global values and faction overrides return to the saved settings. The preset also supports rename, overwrite, and deletion. |
| Open Summary | The formula follows the current scope. Colony size scaling in Formula Options adds the population columns. |
